# Top 3 建议生成规范

## 数据来源

- 只能从 result.json 的 issues 数组中挑选，不得引入 issues 之外的新问题。

## 排序规则

1. 先按 severity 排序：high > medium > low。
2. 同一 severity 内按影响面排序：该规则命中的文件数多者在前；相同则按规则在 rules/_index.md 中的权重高者在前。
3. 取排序结果的前 3 条作为 Top 3。

## 每条格式

- 结构：问题一句话 + 位置（file:line）+ 具体动作。
- 字数上限：每条不超过 80 字（含标点）。
- 位置必须使用 result.json 中该条 issue 的 file 与 line 字段，不得编造。
- 输出时每行一条建议，行首不要加序号或列表符号（渲染报告时自动编号）。

## 禁止事项

- 禁止"建议优化代码""注意代码质量"等不含具体动作的空话。
- 禁止把多条 issue 合并成一条建议。
- 禁止修改 severity 或增删问题。
